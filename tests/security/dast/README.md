# Pruebas de Seguridad Dinámicas (DAST)

Esta carpeta está reservada para la futura integración de herramientas de escaneo dinámico como **OWASP ZAP**.

## Próximos Pasos Recomendados:
1. Configurar un contenedor de OWASP ZAP en el pipeline de CI/CD.
2. Realizar escaneos automáticos contra el entorno de *staging* o *testing* antes de cada despliegue.
3. Analizar los reportes generados para identificar vulnerabilidades como XSS, inyecciones avanzadas y problemas de configuración de encabezados HTTP.
